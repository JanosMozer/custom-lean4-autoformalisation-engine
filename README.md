# High-Throughput Lean 4 Autoformalization

[![Blog Post](https://img.shields.io/badge/Blog-mesh.applied-blue?style=flat&logo=ghost)](https://meshapplied.com/)
[![GitHub Repository](https://img.shields.io/badge/GitHub-JanosMozer%2Fleanbench-black?logo=github)](https://github.com/JanosMozer/leanbench)

A memory-efficient, single-GPU training and inference architecture for formalizing natural language mathematics into Lean 4 statement code using quantized Mixture-of-Experts (`Qwen3-Coder-30B-A3B`), persistent Lean REPL compiler feedback (RLCF GRPO), and dual-tier retrieval augmentation.

For full technical details, empirical results, and system architecture, read the blog post at [mesh.applied](https://meshapplied.com/).
